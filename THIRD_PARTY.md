# Third-party material

## rc505mk2-mcp

`lib/field_map/fx.js` is generated by `tools/mcp_import.js` from rc505mk2-mcp
(https://github.com/hysteve/rc505mk2-mcp), commit
ccc4c1430e33c79f6e27c1eb06541faa00086fd7 (2026-06-21). It holds the FX type
numbers, the FX parameter tags and names, and value tables that the script
probes from the rc505mk2-mcp transforms. `lib/field_map/fx_fixes.js` corrects
some of these entries; each correction states its evidence.

## BOSS RC-505mk2 Parameter Guide

Parameter names and value lists in `lib/field_map/lists.js` and
`lib/field_map/sections.js` come from the RC-505mk2 Parameter Guide (eng02),
Copyright 2021 Roland Corporation:
https://static.roland.com/assets/media/pdf/RC-505mk2_Parameter_eng02_W.pdf
